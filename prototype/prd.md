Web3 DID 个人身份社交平台 产品原型方案（含页面原型 + 交互逻辑）
一、产品核心定位
Web3 去中心化 DID 身份社交平台，以钱包登录 + 链上 NFT 数字身份（纸娃娃形象）+AI 分身代理社交为核心：
去中心化身份：钱包即账号，DID 绑定链上 NFT 身份资产，数据归用户所有
可组装 NFT 纸娃娃：头像、皮肤、服饰、配饰分模块 NFT，自由搭配铸造
AI 人格分身：自定义性格、说话习惯、行为逻辑，AI 代替你社交互动
二、整体页面结构（共 6 大核心页面）
首页（钱包连接登录页）
身份铸造工坊（NFT 纸娃娃组装铸造）
个人 DID 主页（NFT 纸娃娃展示 + AI 分身控制面板）
社交广场（其他用户 DID 主页、AI 分身互动区）
消息聊天页（真人 / AI 分身对话）
资产背包（所有身份 NFT 藏品）
三、逐页面原型图文说明（可直接给 UI / 前端开发）
页面 1：首页・钱包登录页（未连接钱包状态）
页面布局分区
顶部导航栏（全屏通栏）
左侧 Logo：DID AI Verse｜Web3 去中心化身份社交
右侧按钮：【连接钱包】（主按钮，高亮渐变紫）
中间主视觉区（居中）
大标题：铸造你的链上数字分身，AI 替你社交
三段核心卖点：
✅ 钱包一键登录，去中心化 DID 身份
✅ 模块化 NFT 纸娃娃：头像 / 皮肤 / 装备独立链上资产
✅ 自定义 AI 人格，自动社交、聊天、互动
核心行动按钮：【连接加密钱包】
支持钱包列表弹窗：MetaMask、Coinbase、OKX、TrustWallet
底部小字提示：登录即生成专属链上 DID 标识，所有 NFT 资产归属你的钱包地址
底部页脚
链上协议说明、DID 白皮书、社交社区入口
交互逻辑
点击连接钱包 → 拉起钱包签名授权，授权成功跳转【身份铸造工坊】；拒绝则停留在首页
页面 2：身份铸造工坊（核心 NFT 纸娃娃铸造页）
左侧栏：纸娃娃实时预览窗口（主视觉）
3D/2D 可动纸娃娃画布，实时预览搭配效果
功能：旋转、缩放、换装预览
底部预览信息：当前组合预估 Gas、铸造按钮【铸造专属 DID 身份 NFT】
中间分区：模块化藏品分类选择（NFT 组件库）
分 4 大分类标签，可切换：
头部 NFT：头像、发型、面部妆容（独立 NFT）
基底皮肤 NFT：肤色、体型、基础特效
服饰装备 NFT：上衣、下装、外套、翅膀、光环
配饰 NFT：眼镜、挂件、手持道具、背景
每个素材卡片标注：
是否持有、铸造单价、链上稀有度（普通 / 稀有 / 史诗 / 传说）
点击素材 → 实时替换左侧纸娃娃预览
右侧栏：铸造参数设置
DID 身份名称（链上永久名称，不可重复）
身份简介（同步到个人主页展示）
铸造配置：
选择公链（Polygon/BSC/ETH）
铸造数量（仅 1 份专属 DID 主 NFT，配件为多份可交易 NFT）
费用明细：铸造 Gas 费、素材 mint 费
底部按钮：【确认铸造】
点击后钱包发起交易，上链成功提示：DID 身份 NFT 已生成，跳转个人主页
铸造完成后规则
整套搭配绑定主 DID-NFT，所有配件存入【资产背包】
配件 NFT 可单独交易、转让，更换后主页纸娃娃实时更新
页面 3：个人 DID 主页（核心展示 + AI 分身控制台）
页面分左右双栏布局
左栏：DID 身份展示区（公开可见）
顶部信息卡片
链上钱包 DID 地址、自定义昵称、铸造时间、链上 NFT 合约链接
数据标签：AI 分身活跃度、社交互动数、持有 NFT 装备数量
中央大画布：动态 NFT 纸娃娃（可点击放大查看链上藏品元数据）
下方公开社交功能按钮（访客可见）
发起聊天（可选择：和本人真人对话 / 和对方 AI 分身对话）
收藏该 DID 身份、查看对方全部装备 NFT、关注 DID
右栏：私有 AI 分身配置面板（仅本人可见）
模块 1：人格基础设定
基础人设下拉：高冷 / 温柔 / 搞笑 / 理性 / 二次元 / 商务等模板
自定义性格文本框：自由输入性格描述（例：话少毒舌、喜欢分享 Web3 知识、讨厌空话）
语气风格：短句干练 / 长篇细腻 / 幽默玩梗 / 正式专业
模块 2：行为习惯设置
回复速度：秒级快速回复 / 模拟人类延迟（30s-5min 随机）
聊天偏好：喜欢聊 NFT、链游、AI、日常生活；规避话题自定义黑名单
社交行为：主动打招呼、主动分享藏品、被动等待搭话
模块 3：AI 权限开关
自动接待访客：开启后有人进入主页，AI 主动发起对话
自动回复私信：离线时 AI 全权代为聊天
记忆功能：AI 记住过往聊天记录，保持人设统一
紧急接管开关：一键暂停 AI，所有消息转为仅本人可见
底部操作按钮
【保存人格配置】同步上链绑定你的 DID NFT；【重置 AI 人设】清空所有设定
页面 4：社交广场（公共流量页）
顶部筛选栏
筛选条件：最新铸造 DID、高活跃度 AI 分身、稀有 NFT 装备、关注列表
流式卡片布局（每张卡片为一个用户 DID 预览）
单卡片内容：
缩略版纸娃娃形象
用户 DID 昵称、钱包地址简写
AI 分身标签（例：搞笑型 AI、Web3 科普分身）
快捷按钮：进入主页、一键和 AI 分身聊天
侧边推荐栏
好友 DID、热门链上身份 NFT 榜单
页面 5：消息聊天界面
左侧会话列表
区分两种会话类型：
真人会话：对方在线则真人回复，离线自动切换对方 AI 分身
AI 分身专属会话：直接和对方数字分身独立对话
右侧聊天窗口
顶部栏：对方纸娃娃头像、DID 名称、切换聊天对象（真人 / AI）
聊天消息流：文字 / 图片 / NFT 藏品分享
底部输入框：发送文字，支持一键发送自己的装备 NFT 展示
特色功能：查看本次对话 AI 性格设定、导出对话记录
页面 6：资产背包
分类标签：DID 主身份 NFT、头部藏品、皮肤、服饰、配饰
每个 NFT 卡片：
链上哈希、持有数量、交易按钮、穿戴按钮
点击【穿戴】，一键同步更新个人主页纸娃娃形象
四、产品核心交互流程（完整用户链路）
进入首页 → 连接钱包签名登录，生成专属链上 DID 标识
跳转铸造工坊，挑选头像 / 皮肤 / 装备 NFT 组件自由搭配纸娃娃
支付 Gas 铸造整套身份 NFT，配件存入背包
自动跳转个人 DID 主页，展示专属动态纸娃娃
在右侧面板自定义 AI 分身性格、行为习惯并保存
前往社交广场浏览其他用户 DID 主页
可主动发起聊天，对方离线时由其 AI 分身自动交流
随时回到背包更换装备，主页纸娃娃实时刷新外观
五、原型交付补充（可直接交付设计师）
视觉风格：赛博 Web3 风，深色底色 + 紫蓝渐变霓虹，2D 卡通纸娃娃画风
链上标识统一：所有 NFT 组件右上角添加合约链标
AI 分身区分标识：AI 对话气泡带机器人小图标，真人无标识
适配：PC 端 Web 原型，支持多钱包弹窗、链上交易弹窗、NFT 元数据弹窗
